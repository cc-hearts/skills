# 审美方向预设（参考值，不是标准答案）

每个方向给四样东西：主张样例、铁律样例、参考 token、verify 规则差异。
生成时必须结合用户的领地与反推结果调整，不要原样照抄。

## 纸感编辑风（样板 assets/xuan-template/ 即此方向）

- **主张样例**：层级靠字阶和留白，不靠颜色和阴影。
- **铁律样例**：① 一种主色，面积 ≤5%，只给链接/当前态/焦点 ② 三档暖灰各司其职，禁冷灰、禁裸色值 ③ 层级靠字号与字族，中文 500 封顶，禁硬阴影
- **参考 token**：纸 `#f6f2ea` / `#fbf8f2` / `#ece5d8`，线 `#ddd4c3` / `#c3b8a2`，墨 `#2d2922` / `#6f675a` / `#a49a88`，主色三件套示例（赭石）`#b4532a` / `#8a3d1e` / `#f3e5dc`
- **字体**：serif 承担层级（Noto Serif SC），引文楷体（LXGW WenKai Screen），正文 sans，代码 mono；标题 500 封顶
- **形状与深度**：圆角 ≤12px（胶囊 999px）；深度只有边框、井、whisper、ring 四种
- **verify 规则**：禁裸色值 / 禁冷灰色阶 / 禁 ≥600 字重 / 禁硬阴影 / 禁 >12px 圆角

## 冷静极简

- **主张样例**：层级只靠字阶，一切装饰都是噪音。
- **铁律样例**：① 界面 95% 是白、灰、黑，彩色只允许一个 accent ② 层级只靠字号与间距，禁装饰线、禁图标堆砌 ③ 零阴影，分割只用留白和一条 1px 线
- **参考 token**：底 `#fafafa` / `#ffffff`，墨 `#1a1a1a` / `#555555` / `#999999`（中性灰在此方向合法），accent 可选一个冷调（如钴蓝）或干脆黑白分明
- **字体**：sans 为主；如需多字重，选字重齐全的字体族（如 MiSans、HarmonyOS Sans）后标题可用 600；中文 500 封顶的建议保留，除非确认字体族有真实中间字重
- **形状与深度**：小圆角或直角统一一种；无阴影
- **verify 差异**：删除"禁冷灰"检查；可加"彩色出现次数"的人工检查项写进决策表

## 高对比现代

- **主张样例**：对比度就是层级——深底、亮字、一处高亮。
- **铁律样例**：① 深色底 + 高对比文字，正文对比度 ≥7:1 ② 一个高亮色只给关键操作与数据 ③ 直角或统一小圆角，几何感，禁渐变堆砌
- **参考 token**：底 `#111312` / `#1a1d1b`，字 `#f2f0ea` / `#a8a49c`，高亮一个饱和色（荧光绿、电光蓝或品牌色）；"wash"思路改为高亮色的低透明深态
- **字体**：sans 为主，字重对比可以拉大（300 配 600，前提是字体族有真实字重）；mono 用于数据与版本号
- **形状与深度**：直角或 4px；阴影允许带色 glow，但必须在铁律里写明规则，不能随手加
- **verify 差异**：增加亮字清单检查（正文颜色必须在允许清单内）；"禁硬阴影"改为"阴影只能是高亮色 glow"

## 通用提醒

- 三个方向可以混合（如"纸感 + 极简"），混合时铁律取两者交集，规则数仍然 ≤10。
- 换方向后样板里的反面示例必须同步重写——反面示例引用的是本系统的禁用写法，不是样板的。
- webfont 引入方式照抄样板头部（npmmirror 的 fontsource 分包）；换字体族时确认 CDN 有对应包再写进 tokens。
